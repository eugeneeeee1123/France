Primary/secondary/ghost action button in the monumental gold-on-navy voice, uppercase tracked label type - use for all CTAs and module actions.

```jsx
<Button variant="primary" size="md" onClick={() => {}}>Explorer</Button>
<Button variant="secondary">Découvrir</Button>
<Button variant="ghost" disabled>Verrouillé</Button>
```

Variants: `primary` (solid gold), `secondary` (hairline border, gold text), `ghost` (text only). Sizes: `sm`, `md`, `lg`. No spring/bounce animation - buttons must feel instant.
