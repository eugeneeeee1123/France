Thin-line icon (Hexagone set, copied from mockup v3 SVGs) — use for secondary wayfinding beside numerals, stats, Why/How/What and social buttons; never instead of the module numeral.

```jsx
<Icon name="arrowRight" size={14} strokeWidth={1.8} />
<Icon name="compass" size={24} color="var(--mod-arsenal)" />
```

Names: search, arrowRight, compass (Why), sun (How), document (What), target (ZEE), person, speech, anchor, star (P5), camera, play, hexagon. Inherits `currentColor`. Never mix with filled icons or another library.
