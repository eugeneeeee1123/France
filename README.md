## 1. 项目定位与命名规范

### 1.1 命名体系与使用边界
本项目严格区分内部工程代号与公开品牌名称，在代码与展示层执行以下边界：
- **`HEXAGON`（内部工程代号）**：用于 Git 仓库名、代码包名、目录路径（如 `hexagone/`）、模块数据键名与架构设计文档中。
- **`La France en Profondeur`（法兰西的深处 / 战略图册，对外公开品牌）**：面向读者的统一标识，出现在页面 `<title>` 标签、Open Graph 社交分享卡片、首页副标题以及导航栏主标识区域。两者严禁混用。

### 1.2 产品定位与受众
- **定位**：国家战略图册与学术档案（Editorial Atlas / Museum Dossier）。本项目不是泛泛罗列旅游景点的百科全书，也不是虚构军事推演游戏，而是一套严谨、节制、具象剖析法国国家能力的结构化数字图册。
- **目标读者**：关注欧洲防务、关键工业体系、全球治理与文化地缘，且需要通过法文、英文或中文深入理解现代法国国家运作逻辑的学者、研究人员与专业读者。
- **三语体系**：支持法文（`fr`）、英文（`en`）、中文（`zh`）。法文版本保持国书档案级的庄重语感；中文译本遵循严谨书面语体系，杜绝机器翻译腔与口号式表达；核心词汇 `GRANDEUR` 跨语言保持法语原文不予翻译。

## 2. 核心命题与全站叙事矩阵

### 2.1 贯穿命题 (La Grande Question)
全站 11 个页面（1 个全景入口首页 + 10 个独立主权领域模块）共同回答同一个事实问题：

> **为什么法国在 21 世纪依然拒绝接受普通欧洲中等国家的定位，并持续维持全球维度的战略行动能力？**

页面不采用割裂的章节组织方式，而是以统一的 **Why（动因与理念）→ How（机制与制度）→ What（指标与成果）** 认知路径，将防务、工业、疆域、外交与科研紧密嵌合成一套互为条件的国家运作系统。

## 3. 十个主权模块全景研判 (Why → How → What)

### 01 · ARSENAL（防务沙盘）
- **核心逻辑**：法国自1960年“蓝色沙鼠”（Gerboise Bleue）首次核试验起确立独立威慑能力，其防务哲学核心在于“不依赖北约第七条防御伞的自保权”。
- **硬件序列**：
  - 海基威慑：4艘凯旋级战略核潜艇（SNLE），每艘搭载16枚M51潜射洲际弹道导弹；第三代战略核潜艇（SNLE 3G）处于研制序列，计划2035年起交付。
  - 空基威慑：战略空军（FAS）与海军核航空兵（FANu），以阵风F4搭载ASMP-A超音速核巡航导弹；下一代ASN4G高超音速核导弹预研中。
  - 常规打击：叙弗朗级（Suffren）攻击核潜艇部署巡航导弹，戴高乐号核动力航母常态化战备巡航；PANG下一代核动力航空母舰计划2038年服役。
- **关联流动**：与 `industry` 模块挂钩（达索机体制造、赛峰M88发动机与斯奈克玛固态燃料火箭发动机），向 `territories` 提供海外安全前哨保护。

### 02 · STATECRAFT（国家治理）
- **核心逻辑**：宪法赋权的行政决策集中度，避免了多党议会制在重大防务决策中的冗长拉扯。
- **机制要点**：
  - 第五共和国宪法第15条确立共和国总统为三军统帅，拥有核武器最终发射权。
  - 戴高乐外交路线：在美苏两极与大国博弈中维持“平衡力量”（puissance d'équilibre），坚持在欧洲防务框架中保持技术与指挥链自主。
  - 安理会常任理事国地位与广泛的双边防务条约（如与非洲、中东及印太盟国签署的驻军协定）。

### 03 · ÉPOCHES（历程纪元）
- **核心逻辑**：今日法国的中央集权行政机制与国防动员传统，均由历史上剧烈的政体断裂演化而来。
- **关键历史节点**：
  - 公元前52年：阿莱西亚战役，高卢被罗马征服，罗马法制与城市规划体系植入。
  - 17世纪：路易十四建立官僚集权与常备陆军，柯尔贝尔推行重商主义，奠定国家工商业指导传统。
  - 1789年：法国大革命，推翻封建等级制，确立“人民主权”与现代民族国家概念。
  - 1804年：《法国民法典》（拿破仑法典）颁布，奠定大陆法系法律理性化地基与中央集权行政区划。
  - 1940–1944年：法兰西战役溃败与维希政权；戴高乐在伦敦发起“自由法国”运动，重建国家合法性。
  - 1958年：阿尔及利亚危机催生第五共和国，新宪法奠定半总统制架构与战略自主根基。

### 04 · TERRITOIRES（全球疆域）
- **核心逻辑**：欧洲大陆面积的有限性，被广袤的海外领土网络转化为全球战略纵深。
- **主权切片**：
  - 专属经济区（EEZ）：管辖面积超过1100万平方公里，位居全球第二（仅次于美国），横跨大西洋、印度洋、太平洋与南大洋。
  - 战略前沿点位：法属圭亚那（欧洲航天发射场，地理位置近赤道，提供极高的火箭入轨载荷效率）；留尼汪与马约特（FAZSOI驻军监控莫桑比克海峡海上交通线）；法属波利尼西亚与新喀里多尼亚（南太平洋地缘支点与镍矿资源）。

### 05 · ARENA（竞技体育）
- **核心逻辑**：竞技体育作为公共投资的重要部分，承担了共和国价值观输出与不同族群归属感塑造的职能。
- **机制与成果**：
  - 克莱枫丹国家足球学院（INF Clairefontaine）：全额公共资助的严格选拔机制，为各级国家队与欧洲主流联赛持续输送人才。
  - 融合范式：1998年“Black-Blanc-Beur”（黑人-白人-阿拉伯人）世界杯夺冠阵容成为法国现代多元社会共识的具象符号；2018年阵容传承并巩固了这一融合路径。

### 06 · AESTHETICS（美学主权）
- **核心逻辑**：将文化视作与粮食、武器同等重要的国家主权组成部分，拒绝将其完全交由国际贸易市场机制调节。
- **制度护城河**：
  - “文化例外”法案：在关贸总协定（GATT）与世贸组织（WTO）谈判中坚持将视听作品排除在纯粹自由贸易之外。
  - 国家电影与动态图像中心（CNC）：对影院票房与流媒体点播收入抽税，设立专项基金定向补贴本土独立电影与青年导演创作。
  - 博物馆与艺术博览会：卢浮宫、奥赛与蓬皮杜中心掌握古典与现代艺术藏品体系，巴黎时装周保持全球时装行业标准的裁定权。

### 07 · SCIENCE（战略科研）
- **核心逻辑**：国家直接组织大规模科研攻关，聚焦事关能源安全、主权防务与未来算力的战略前沿。
- **科研中枢**：
  - CNRS（国家科学研究中心）：欧洲最大的基础科学研究机构，常年产生诺贝尔物理/化学奖与菲尔兹数学奖学者。
  - 空间与核聚变：CNES主导阿里安火箭发射体系，卡达拉舍（Cadarache）承载全球最大的核聚变反应堆ITER建设。
  - 人工智能与半导体：巴黎高等师范学院等高校培养的数理人才支撑了以Mistral AI为代表的开源大语言模型阵营。

### 08 · ÉCONOMIE（经济底盘）
- **核心逻辑**：以高度资本化的奢侈品工业、全球农业出口创汇与稳定的民用核能电力输出，对冲制造业外移带来的冲击。
- **经济支柱**：
  - 能源与公用事业：EDF核电机组保障法国本土70%左右的电力供应，并维持对西欧邻国的大规模电力净出口。
  - 全球消费与资本沉淀：LVMH、开云（Kering）与爱马仕（Hermès）占据全球高档消费品利润制高点，充当法国私人资本蓄水池。
  - 农业自主：得益于广阔肥沃的盆地平原与共同农业政策（CAP），法国常年维持欧洲第一大粮食输出国地位。

### 09 · FRANCOPHONIE（法语共同体）
- **核心逻辑**：语言既是文化载体，也是政治协商与跨国商贸合作的天然通道。
- **演化网络**：
  - 现有版图：法语国家及地区国际组织（OIF）涵盖88个成员国与观察员国，在联合国、欧盟等多边机构维持法定工作语言地位。
  - 非洲增长极：随着撒哈拉以南非洲法语国家（如塞内加尔、科特迪瓦、刚果金）的人口快速增长，法语使用者总数将在2050年突破7亿，构成法国拓展全球经贸往来的纵深地带。

### 10 · INDUSTRY（关键工业）
- **核心逻辑**：没有独立完整的工业制造链，防务与外交的战略自主将沦为空谈。
- **全产业链拓扑**：
  - 航空军工：达索飞机（Dassault Aviation）、赛峰动力（Safran）、泰雷兹航电（Thales）构成的军机自研铁三角。
  - 核燃料闭环：从奥拉诺（Orano）的铀浓缩、燃料制造，到EDF核电站运营，再到拉阿格（La Hague）核废料后处理工厂，形成全球罕有的完整核循环体系。
  - 先进材料与微电子：Soitec绝缘体上硅（FD-SOI）材料专利、意法半导体（STMicroelectronics）车规芯片制造。

## 4. 设定与推演准则 (R.I.F. / GDN-2040)

在本项目的内容编排中，包含部分基于法兰西第五共和国防务规划法案（LPM）及2035–2040年地缘推演的宏观设定（代号 R.I.F. / GDN-2040）。为确保学术与事实严肃性，全站严格遵循以下约定：

1. **设定标注红线**：所有推演性质的数字与装备，必须附带 `ScenarioLabel` 组件（如标明 `设定 · GDN-2040` 或 `(scénario)`）。每页正文仅在页面顶部设立一处醒目的世界观推演声明，严禁在页面各处重复堆叠免责声明破坏阅读体验。
2. **严禁伪造照片**：尚未正式服役或属于概念阶段的装备（如阵风F5/F6、Corbeau战略隐身无人机、PANG核动力新航母），统一采用规范标注的概念线框占位图或3D白模渲染图，坚决禁止使用虚假合成实物照片冒充现实已服役装备。
3. **数据双轨对照**：在核心模块（如 ARSENAL）中，明确列出现实公开发布数据（如 SIPRI 2025 报告）与推演数据的对照范围，杜绝将推演数据与当下现实混淆。

## 5. 前端工程与技术栈架构

### 5.1 核心依赖与运行环境
- **Node.js**：`>= 20.x`
- **框架**：Next.js `16.4.2`（采用 App Router 架构与 React Server Components 服务端组件优先模式）
- **渲染库**：React `19.3.0` + React DOM `19.3.0`
- **语言**：TypeScript `5.x`（严格模式开启，禁止隐式 `any`，严格类型推导）
- **样式**：Tailwind CSS `v4`（配合 CSS 现代变量与原生 CSS 嵌套语法）
- **国际化**：`next-intl` `^4.14.9`（服务端路由适配，无客户端中间件重定向闪烁）
- **三维与图形**：Three.js `^0.186.1`、`@react-three/fiber` `^9.8.2`、`@react-three/drei` `^10.7.9`、`react-force-graph-2d`

### 5.2 路由与国际化方案 (`next-intl`)
应用以 `hexagone/src/app/[locale]` 为根路由层级，通过 `generateStaticParams()` 在构建阶段为每种语言预渲染全部静态页面：
- `/fr`（法文首页）、`/en`（英文首页）、`/zh`（中文首页）
- `/[locale]/arsenal`、`/[locale]/statecraft`、`/[locale]/epochs`、`/[locale]/territories`、`/[locale]/arena`、`/[locale]/aesthetics`、`/[locale]/science`、`/[locale]/economy`、`/[locale]/francophonie`、`/[locale]/industry`
- 辅助页面：`/[locale]/about`、`/[locale]/credits`、`/[locale]/legal`、`/[locale]/sources`

### 5.3 模块元数据模型 (`modules.ts`)
全站模块路由、色相、跨模块连接关系全部汇聚于 `src/lib/content/modules.ts`，充当全站统一配置枢纽：

```typescript
export type ModuleId =
  | 'arsenal' | 'statecraft' | 'epochs' | 'territories' | 'arena'
  | 'aesthetics' | 'science' | 'economy' | 'francophonie' | 'industry'

export interface Module {
  id: ModuleId
  n: string              // 两位编号 '01' 至 '10'，核心寻路主标号

  scenario?: boolean     // 是否含有 GDN-2040 设定数据
  navVisible: boolean    // 是否在宽屏导航栏顶层直显（前 7 个直显，后 3 个收纳于折叠菜单）
}
```

## 6. Hexagone Design System 视觉与交互规范

### 6.1 色彩与色阶系统 (Tokens)
遵循深邃墨色调（Dark-only）原则，全面弃用纯白（`#FFFFFF`）与纯黑（`#000000`），避免高对比刺眼疲劳，建立典雅的法国国家档案馆质感：
- **底色墨色阶 (Ink Ramp)**：
  - `--color-ink-950`: `#000D1F`（极深基底）
  - `--color-ink-900`: `#00152C`（主页面背景）
  - `--color-ink-800`: `#001B39`（卡片与导航底色）
  - `--color-ink-700`: `#04264B`（组件默认边框色）
  - `--color-ink-600`: `#12385F`（悬浮状态与二级分界线）
- **文字与界面前景色**：
  - `--color-paper-50`: `#F3EFE4`（暖宣纸色，正文与主要文字，不透明度 85%）
  - `--color-paper-muted`: `#B9C3D1`（冷灰辅助说明字）
- **行动标定色 (Action Gold)**：
  - `--color-gold`: `#EFB44B`（香槟金，全站唯一行动引导与高光确认色）
  - `--color-gold-rule`: `#B8863A`（暗金边框与细线）
- **模块独立色相 (Module Hues)**：
  - 每个模块在 OKLCH 色彩空间中分配固定的色相角（固定明度 68%、色度 0.1）：
    - 01 Arsenal: `hue: 236`（军工深蓝）
    - 02 Statecraft: `hue: 272`（国政靛紫）
    - 03 Epochs: `hue: 56`（历史古铜）
    - 04 Territories: `hue: 200`（大洋天青）
    - 05 Arena: `hue: 20`（竞技赤褐）
    - 06 Aesthetics: `hue: 344`（文化绯红）
    - 07 Science: `hue: 164`（科研松绿）
    - 08 Economy: `hue: 308`（经贸紫红）
    - 09 Francophonie: `hue: 128`（法语草木绿）
    - 10 Industry: `hue: 92`（关键工业金黄）
  - *使用原则*：模块专属色仅用于编号角标、发丝外框、发光扩散环（Glow）与高亮悬浮，绝不允许侵入正文字体颜色。

### 6.2 字体排印体系 (Typography)
- **西文字体**：
  - 大标题与纪念碑文字：`Playfair Display`（衬线字体，字偶间距展开 `0.05em`，呈现国书雕刻感）。
  - 正文与交互组件：`Public Sans`（无衬线字体，现代克制，极高可读性）。
  - 数据与技术参数：`IBM Plex Mono`（等宽字体，数字严格对齐）。
- **中文字体**：
  - 标题采用 `思源宋体`（Noto Serif SC）；正文与 UI 采用 `思源黑体`（Noto Sans SC）。
  - 中文段落设置专属行高（`line-height: 1.8`），字重采用中粗（Medium/SemiBold），消除 CJK 排版密集感。
- **排印禁令**：正文禁止出现感叹号；禁止使用 Emoji 表情充当列表符号；除专用破折号排版外，正文禁用长破折号（Em-dash）；法文冒号前面必须保留非截断空格。

### 6.3 布局与微交互原则
- **边框与角处理**：全站卡片与输入容器采用 `0px` 绝对方角（Square corners），不使用圆润的大角。卡片边框采用 1px 发丝细线（Hairline Rule）。
- **动效减速曲线 (Settle Curve)**：页面级交互统一使用减速贝塞尔曲线 `cubic-bezier(0.16, 1, 0.3, 1)`。
- **无障碍保障**：全面兼容 `prefers-reduced-motion`，当系统开启减弱动效时，所有位移动画自动平替为简单的透明度淡入淡出（Opacity swaps）。

## 7. 三维图形与拓扑可视化管线

### 7.1 Blender 铁塔程序化建模 (`blender_eiffel/`)
- **生成架构**：采用 Python 脚本 `generate_eiffel_tower_v2.py` 通过 Blender Python API（`bpy`）进行程序化建模。
- **结构拆解**：
  1. 四角底座倾斜支撑立柱与双向加强横梁
  2. 第一层平台穹顶支撑拱结构与细密桁架网格
  3. 第二层中转平台与双层护栏格栅
  4. 上层渐缩高耸塔身、柱状结构与避雷天线顶尖
- **导出与格式优化**：
  - 模型生成为 `eiffel.blend`，并通过自动化脚本导出为 `.glb` 格式二进制文件。
  - 运行 `prepare-eiffel-glb.mjs`，调用 `@gltf-transform/cli` 剔除冗余材质节点，执行 Draco 网格几何压缩与 KTX2 贴图格式转换，将原本数十兆的高精模型精简至受控尺寸，确保网络快速加载。

### 7.2 Three.js 客户端按需加载岛 (`EiffelScene.tsx`)
- 首页埃菲尔铁塔模型不在首屏服务端构建中阻塞渲染，而是封装为客户端独立组件：
  - 采用 `next/dynamic` + `Suspense` 异步包裹，并提供与最终三维场景尺寸完全一致的深蓝发丝框骨架占位屏。
  - 基于 `@react-three/fiber` 的 `<Canvas>` 实现阻尼物理拖拽（Damping Orbit Controls），设置水平转角约束与俯仰角度边界。
  - 禁止无意义的无限自转循环，避免用户放置后台时无端消耗 GPU 算力。

### 7.3 产业拓扑力导向图 (`IndustryNetworkGraph.tsx`)
- **拓扑核心**：基于 `react-force-graph-2d` 封装，呈现法国关键工业网络的紧密咬合关系。
- **坐标固化**：中心根节点 `FRANCE` 坐标硬编码固定在 Canvas 原点（`fx: 0, fy: 0`），避免模拟引擎初始化时的剧烈晃动。
- **渲染工艺**：Canvas 2D 上层手绘双层同心发光环（Double-Bezel），根据所属工业集群（军工、航天、能源、半导体、软实力）分配专属 OKLCH 环状光晕。
- **联动抽屉**：点击次级节点（如达索、赛峰、意法半导体）触发弹性滑入侧边研判卡片，清晰展现该实体对国家主权的支撑机制、上下游协作网络，并支持 `/arsenal#rafale` 跨模块深层锚点直达。

## 8. 质量检验与自动化门禁系统

为确保项目具备工程级的健壮性与排版纯净度，项目在 `hexagone/package.json` 中配置了严格的 `npm run verify` 一键全检自动化门禁，由 7 道独立检验关卡串联而成：

```bash
npm run verify
```

### 8.1 七道门禁流水线解析
1. **TypeScript 类型检验 (`tsc --noEmit`)**：
   - 全面验证全站 70+ 个 TypeScript 文件，禁止类型推导漏洞与未经声明的属性访问。
2. **ESLint 严格语法审计 (`eslint . --max-warnings 0`)**：
   - 实行零容忍规则，只要存在 1 处 ESLint Warning 即直接判负中断流程。
3. **多语言词条对齐检测 (`check-messages.mjs`)**：
   - 自动对比 `messages/fr.json`、`messages/en.json` 与 `messages/zh.json`，确保三份语言字典在对象嵌套深度、键名命名与缺失情况上保持 100% 镜像对称。
4. **禁止词与文风红线扫描 (`check-banned.mjs`)**：
   - 全自动扫描源码与词条文件，坚决拦截违禁模式：
     - 禁止词汇拦截：拦截 "delve"、"tapestry"、"testament" 等典型机器生成词汇。
     - 假大空与中二文风拦截：杜绝“命脉”、“核心叙事”、“战略底牌”、“赋能”、“不仅……更是……”等空洞排比口号。
     - 样式污染拦截：严禁在非全局 CSS 中修改 `body`、`html` 或 `*` 全局选择器。
5. **静态路由预渲染生成 (`next build`)**：
   - 真实执行 Next.js 构建引擎，为法、英、中三语共 15+ 个路由生成完全静态的 HTML 产物，确保在禁用 JavaScript 环境下页面核心文字依然完备可读。
6. **产物结构与静态标记验证 (`check-static-html.mjs`)**：
   - 深入 `.next/server/app` 目录，检查预渲染的 HTML 产物，验证 `lang` 属性声明、`<title>` 标签合规性、FFF 队徽尺寸属性以及无障碍辅助信息。
7. **客户端 JavaScript 预算控制 (`check-js-budget.mjs`)**：
   - 对首屏打包产物实施硬性体积预算监控，确保首屏加载的 JS 客户端代码保持在极小预算内，避免臃肿脚本拖慢首屏绘制时间。

## 10. 本地开发与部署运维指南

### 10.1 本地开发环境配置
1. **进入工程目录**：
   ```bash
   cd "hexagone"
   ```
2. **安装工程依赖**：
   ```bash
   npm install
   ```
3. **启动本地开发服务器**：
   ```bash
   npm run dev
   ```
   启动后打开浏览器访问 `http://localhost:3000`，本地中间件会自动将根路径重定向至默认语言路由（如 `/fr` 或 `/zh`）。

### 10.2 执行质量检验与静态构建
在提交代码或准备发布前，必须在 `hexagone` 目录下运行完整质量门禁：
```bash
npm run verify
```
若全部通过，可直接生成生产部署静态包：
```bash
npm run build
```

### 10.3 部署运维要点
- **平台适配**：由于全站采用 Next.js App Router 静态生成技术（SSG），构建产物可零配置直接部署于 **Vercel**，亦可导出为纯静态资产托管在 Cloudflare Pages、AWS S3 或 GitHub Pages。
- **三维模型传输**：生产环境中的 `eiffel.glb` 与图片资源位于 `public/` 目录下，部署平台需配置长期缓存策略（Cache-Control）并开启 Gzip / Brotli 压缩。

## 11. 多 Agent 协同协议与行为准则

本项目开发工作由多款 AI 协同助理（Claude, Antigravity, Codex, Grok）配合人类开发者共同推进，各角色在工程中遵循严格的分工边界与行为禁令：

### 11.1 四方协作分工矩阵
- **Claude**：负责需求拆解、全站架构规划、阶段性方案统筹与任务 Brief 编写。不直接操刀大段面向用户的最终发布文案。
- **Antigravity (agy / Gemini 3.8 Flash)**：负责全站面向用户的三语正式文案创作、界面细粒度代码修改以及代码注释保全。强制挂载 `anti-ai-slop-writing`、`humanizer` 等规范技能，确保文字具备学术与档案质感。
- **Codex (GPT-5.6 / 6.1)**：负责复杂业务逻辑、数据结构定义、力导向拓扑算法实现及多语言键值完整性校对。
- **Grok (Grok 4.7 High)**：负责架构方案争鸣、技术选型评判与深层次代码审查（Review）。

### 11.2 代码修改与完整性保护红线
1. **严格范围限制 (Strict Scope Control)**：严禁在未授权的情况下擅自“顺手重构”现有变量名、函数名或 CSS 类名；仅在用户明确指出的代码块内进行精确操作。
2. **严禁删除注释 (Preserve Comments)**：源码中的所有设计说明、历史决策注释与接口文档必须 100% 完整保留，禁止在修改代码时清理任何既有注释。
3. **格式一致性与禁止清空**：严格沿用目标文件原有的缩进与语法风格；大型文件必须通过增量差分（Diff/Patch）方式修改，严禁清空原文件全量覆写。
4. **CSS 隔离原则**：禁止向全局选择器（如 `body`, `*`, `div`）随意追加覆盖样式，必须通过独立的 ID、模块专属 Class 或 Tailwind 工具类实现样式局部收敛。
